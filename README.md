# Sorteo Noche de Terror — Ruleta 0001 - 2000

Aplicación web de ruleta horizontal estilo lootbox para el sorteo del evento **Noche de Terror (Halloween Edition)** por Eclipze Events & Fumeteo Productions.

## Características
- **Rango numérico:** 0001 al 2000 en boletos de papel rasgado.
- **Física de giro:** Desaceleración progresiva continua de 20 segundos.
- **Efectos sonoros:** Tañidos de campana gótica ("BONG") y remate cinemático de terror con Web Audio API.
- **Celebración:** Modal con boleto premiado ampliado y confeti.
- **Tecnologías:** React 18, TypeScript, Tailwind CSS, Vite.
