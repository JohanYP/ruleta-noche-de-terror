# Sorteo Noche de Terror — Ruleta 0001 - 2000

Aplicación web de ruleta  estilo lootbox para el sorteo del evento **Noche de Terror (Halloween Edition)** por Eclipze Events & Fumeteo Productions.

## Uso

- **¡GIRAR RULETA!** inicia el sorteo; el número ganador sale entre 0001 y 2000.
- **⚙ (arriba a la derecha)** permite cambiar la duración del giro en segundos: solo números enteros, mínimo 10, sin máximo. Se recuerda en el navegador.

## Desarrollo

```bash
pnpm install
pnpm dev      # http://localhost:5174/ruleta-noche-de-terror/
pnpm build
```

Cada push a `main` se publica en GitHub Pages.
